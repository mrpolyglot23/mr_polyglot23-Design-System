# Mr. Polyglot — Design System

Brand design system for **@mr_polyglot23** (Sumeru Paul).

*Speak first. Study second.*

## What's here

| File / folder | What it is |
|---|---|
| `DESIGN.md` | The full brand spec: colors, typography, spacing, platform canvases, components, imagery, production workflows. Start here. |
| `assets/logos/` | Wordmark and logo files (SVG or PNG) |
| `fonts/` | Optional: font files (all six families are free on Google Fonts) |

## Quick reference

- **Core colors:** bronze `#6E5E46` · oxblood `#8A3B2E` · ink `#1B1916` · paper `#F3EFE6` · sand `#C9BCA0`
- **Dark set:** near-black `#14120F` · dark-brown `#2A241C` · gold `#C9A96A` · cream `#F4EFE6` · light-sand `#E6DCCB`
- **Brand type:** Instrument Serif · Space Grotesk · JetBrains Mono
- **Editorial type:** Newsreader · IBM Plex Sans · IBM Plex Mono
- **Rule:** oxblood on light, gold on dark. One accent moment per frame.
